# 대한제국 국가운영기

가상의 대한제국을 운영하는 데스크톱 국가 시뮬레이션입니다.

## 주요 기능
- 국가 개요 대시보드
- 국고, 인구, GDP, 지지율, 안정도, 군사력, 외교 관계 관리
- 경제·재정 정책
- 국민·사회 정책
- 외교 및 주변국 관계
- 국방 운영
- 법률·정책 현황
- 정책 선택에 따른 국가 지표 변화
- Windows Portable EXE 자동 빌드

## 로컬 실행
Node.js 설치 후:

```bash
cd dahan
npm install
npm start
```

Windows EXE:

```bash
npm run dist
```

이 프로젝트는 실제 국가가 아닌 창작 가상국가 시뮬레이션입니다.

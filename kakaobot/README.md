# 가국경제봇 - 카카오톡 PC 연결형

Windows용 EXE에서 PC 카카오톡의 원하는 채팅방을 선택하고, `>도움말`, `>계좌`, `>국가정보`, `>경제`, `>정책` 등의 명령에 자동 응답하는 가상국가 경제봇입니다.

## 사용법

1. PC 카카오톡에 먼저 로그인합니다.
2. EXE를 실행합니다.
3. 채팅방 이름을 입력합니다.
4. **연결**을 누릅니다.
5. **봇 시작/중지**를 눌러 자동 응답을 켭니다.

카카오톡 PC의 UI/접근성 구조나 버전에 따라 메시지 자동 읽기 부분이 달라질 수 있습니다. 연결 및 메시지 전송은 Windows UI 자동화를 사용합니다.

## 주의

이 프로그램은 카카오톡 계정의 비밀번호나 인증정보를 요구하지 않습니다. EXE가 임의로 방에 초대되는 구조가 아니라, 사용자가 로그인한 PC 카카오톡에서 지정한 방을 열어 자동화합니다.
